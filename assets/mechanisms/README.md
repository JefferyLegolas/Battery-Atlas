# 机制图展示状态

现有 SVG 模板与 JSON 中的 mechanismType / mechanismNote 为历史资源，不再用于页面展示。模板曾跨体系复用，无法保证离子种类、材料、反应方向及失效模型与所选方案一致。不得将这些映射视为已核验机制。

页面直接从当前匹配的 profile 读取 cathode、electrolyte、anode，生成不带反应箭头的材料构成示意，明确标为“非反应机理图”。卡片显示首条命中方案；详情分别展示全部命中方案及其来源，不合并为新配方。

恢复反应机理图前，应为每条适用方案记录原始文献及图号，核对两极材料、载流物种、电荷、充放电方向和适用条件；卡片、详情和放大图必须一致。不能仅凭“存在体积变化”或“发生离子迁移”套用模板。未完成核验时继续使用材料构成示意。

旧 assign-mechanism-types.mjs 和 generate-mechanism-posters.mjs 仅维护历史资源，不会让页面重新启用模板。
