# Battery Atlas · 材料电池图谱

一个面向移动端、可离线使用的材料—电池体系检索工具。它从具体化学材料和结构出发，帮助用户组合正极、负极与电解液／电解质条件，查找已收录的典型电池体系、代表性生产商与公开证据。

**在线浏览：** https://jefferylegolas.github.io/Battery-Atlas/

## 项目定位

Battery Atlas 不是按电池名称反向查材料的普通目录，而是把材料选择放在入口：

1. 选择正极材料；
2. 选择负极材料；
3. 选择电解液或固体电解质；
4. 查看满足这些条件的已收录电池体系；
5. 继续比较性能、商业化阶段、生产商信息和公开证据。

当前页面标注的数据快照包含 **27 个电池体系**，最近核查日期为 **2026-09-09**。

## 核心功能

- **三栏材料筛选**：分别配置正极、负极和电解质条件。
- **清晰的匹配逻辑**：同一栏多选按“或”处理，不同栏之间按“且”处理；空栏表示不限。
- **元素周期表入口**：通过元素查找相关材料，而不是把多个元素或材料自动合并为新配方。
- **预设示例**：快速尝试磷酸铁锂＋石墨、硬碳钠电池、微米硅＋固体电解质等组合。
- **阶段筛选**：区分商业化体系、示范／早期项目和研究中方案。
- **体系档案**：查看材料组合、性能指标、企业关联及证据来源。
- **性能对比**：选择两种电池体系进行并列比较。
- **收藏功能**：收藏保存在当前浏览器中，无需账户。
- **分享链接**：生成包含当前电池或材料筛选条件的链接；分享内容不包含个人收藏。
- **结果与证据导出**：便于后续研究、讨论和资料整理。
- **单文件离线运行**：全部界面、样式、逻辑与数据封装在 `index.html` 中。

## 使用方法

### 在线使用

打开 [Battery Atlas](https://jefferylegolas.github.io/Battery-Atlas/)，选择任意材料条件即可开始检索。

### 本地离线使用

下载仓库后，直接用现代浏览器打开 `index.html`。项目不需要安装依赖，也不需要服务器或构建步骤。

## 数据与证据边界

本项目是持续扩充的公开资料库，并非全球所有电池体系的穷尽清单。

- 出现匹配结果，表示条件命中了已收录的典型体系或文献方案，不等于配方通过认证。
- 未收录某个组合，不代表该组合在物理或工程上不可行。
- 企业与体系的关联不代表该企业采用页面显示的具体实验配方，也不构成统一市场排名。
- 数据不会自动实时更新。
- 页面内容用于检索、学习和初步研究，不替代电化学验证、安全评估、知识产权核查或采购尽调。
